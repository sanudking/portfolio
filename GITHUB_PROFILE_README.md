## About

CSE undergrad at NIT Jalandhar (CGPA 8.31/10) who likes problems that sit between the browser and the metal. Most of what I build starts with a question: how much can consumer devices actually do? That has led me to shard a Transformer across two phones over WebRTC, write a voxel engine's PRNG from scratch, and wire an ESP32 into a milk-quality classifier.

I'm currently going deeper into distributed systems, browser networking and LLM serving internals.

## What I'm building

- **MiniMoL** — a browser-only distributed Transformer inference demo. A 6-layer, 11M-parameter byte-level model is split across two phones; only activations and token IDs cross the peer link. Serverless WebRTC pairing via QR codes, SHA-256 partition checks, CPU-only FP32 inference in Web Workers.
- **JobMatch** — a database-free resume-to-job matcher. PyMuPDF extraction with PII redaction, Adzuna listings, BGE embedding retrieval and Groq evaluation into match scores with matched/missing skills.
